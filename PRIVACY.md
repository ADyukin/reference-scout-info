# Privacy policy

Last updated: November 7, 2026

This policy describes the planned personal Reference Scout integration and this informational website. Reference Scout is an independent project, not affiliated with Pinterest, Inc.

**In brief:** the website does not ask you to sign in or submit personal information. The planned MCP integration reads Pinterest board and Pin information only from the account that authorizes it, and is designed to be read-only.

## Information the website handles

The informational pages do not contain account forms, advertising trackers, or analytics scripts. The website does not receive Pinterest credentials or Pin data. The hosting infrastructure may process basic technical request information, such as IP address, browser headers, and requested page, to deliver and protect the site under the hosting provider's own policies.

## Information the planned integration handles

When the MCP integration is configured by an account owner, it requests board and saved Pin information available to that Pinterest account and authorized by the granted API scopes. This can include board names and descriptions, Pin titles, descriptions, alt text, links, and image URLs. The integration is intended to search the owner's saved material and return matching references to the AI client the owner is using.

The Pinterest access token is supplied by the local MCP host or stored in the owner's operating-system credential store. It is sent to Pinterest's official API to make authorized requests; it is not sent to this website. The integration does not publish, edit, or delete Pins or boards.

## AI client and Pinterest

Search results are returned to the AI client/MCP host selected by the user. That provider may process the text and image URLs as part of the user's request under its own privacy terms. Pinterest processes API requests under its own [Privacy Policy](https://policy.pinterest.com/en/privacy-policy) and developer terms. The user should review those policies before connecting the integration.

## Retention and sharing

Reference Scout does not operate a separate database for Pinterest board or Pin data and does not sell or share such data for advertising. The AI provider, Pinterest, the local MCP host, and the site hosting provider may retain information according to their respective policies and settings. Users can revoke the integration's Pinterest authorization in Pinterest account settings and remove a locally stored token from their operating-system credential store.

## Children

Reference Scout is a general design-research tool and is not directed to children.

## Changes

This policy may be updated if the integration's data handling changes. The date above indicates the latest revision.

## Contact

For privacy questions about the integration, contact the developer through the Pinterest developer account associated with the Reference Scout app. For information handled by Pinterest or the AI client, contact those providers directly.
